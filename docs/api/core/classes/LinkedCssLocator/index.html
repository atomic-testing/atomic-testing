Class: LinkedCssLocator

Defined in: packages/core/src/locators/LinkedCssLocator.ts:40

A CssLocator whose match must also satisfy a value comparison against a second, independently-located target element — e.g. an <option> whose value equals a <select>'s current value. valueExtract describes how to read the value off this locator's own match; matchingTargetLocator / matchingTargetValueExtract describe where to read the value to compare against. Produced by byLinkedElement (experimental).
